# 「看见」See — 视障环境感知辅助 App

> 基于 Android 端实时目标检测与多模态大模型的视障步行障碍预警应用

## 📖 项目简介

「看见」是一款面向视障用户的 Android 出行辅助应用：通过手机摄像头实时识别前方障碍物，结合单目距离估算与方位判断，用语音（TTS）播报障碍物距离与方向，帮助视障人士在人行道上安全行走。

**核心特点**：
- 📷 纯软件方案，零额外硬件成本，一部 Android 手机即可使用
- 🎙️ 语音优先交互，全程无需精确触摸屏幕
- 📵 离线检测保底，无网络也能使用，保护隐私
- ☁️ 有网时自动叠加云端多模态大模型，识别护栏、交通锥等离线模型未覆盖的类别

## ✨ 核心功能

| 功能 | 说明 |
|---|---|
| 实时目标检测 | CameraX 实时取景，TensorFlow Lite 部署 EfficientDet-Lite0 模型，识别行人、车辆、自行车、路牌等 COCO 90 类物体 |
| 距离与方位估算 | 单目视觉估算障碍物距离（米），按画面三等分判断左前方/正前方/右前方 |
| 分级语音预警 | 0.5m 内紧急"小心"；2m 内提示绕行；5 秒冷却防刷屏；仅关注正前方中间区域 |
| 语音控制 | 讯飞离线语音识别，说"找杯子/找椅子"进入寻物模式，支持"停止识别/退出"等命令 |
| 联网增强 | SiliconFlow Qwen3-VL 多模态大模型识别护栏、交通锥、垃圾桶等离线模型不认识的类别，网络状态自动切换 |
| 无障碍输出 | TTS 语音播报 + 屏幕字幕双通道，锁竖屏，打开即用 |

## 🏗 系统架构

```
                    ┌──────────────────────┐
                    │    摄像头实时画面      │
                    │   CameraX 逐帧回调     │
                    └──────────┬───────────┘
                               ↓
                    ┌──────────────────────┐
                    │   TFLite 端侧推理      │
                    │   EfficientDet-Lite0  │
                    │  检测框 / 类别 / 置信度 │
                    └──────────┬───────────┘
                               ↓
              ┌────────────────────────────────┐
              │        双路径识别策略            │
              └────────┬─────────────┬─────────┘
                       ↓             ↓
        ┌──────────────────┐  ┌─────────────────────┐
        │  A. 离线路径（保底）│  │  B. 联网路径（增强）    │
        │  置信度高 → 直接输出│  │  置信度低 / 类别未覆盖 │
        │  无网 / 弱网可用    │  │  → Qwen3-VL 多模态    │
        └────────┬─────────┘  └──────────┬──────────┘
                 └───────────┬───────────┘
                             ↓
                  ┌──────────────────────┐
                  │    距离与方位估算      │
                  │ 单目测距 + 画面三等分  │
                  │  左前方/正前方/右前方   │
                  └──────────┬───────────┘
                             ↓
                  ┌──────────────────────┐
                  │      分级播报决策      │
                  │ 0.5m 紧急 / 2m 绕行   │
                  │ 5s 冷却 / 正前方过滤  │
                  └──────────┬───────────┘
                             ↓
                  ┌──────────────────────┐
                  │   TTS 语音 + 屏幕字幕   │
                  └──────────────────────┘

        ↕ 语音指令（讯飞离线识别）："找杯子" → 寻物模式
                                    "停止识别" / "退出"
```

**设计要点**：

- **双路径而非二选一**：端侧保证「永远可用」，云端保证「认得更多」，按网络状态与置信度自动切换
- **播报分级**：不是检测到就播，而是按危险程度排序，避免信息过载（视障用户无法同时处理多条语音）
- **冷却与区域过滤**：5 秒冷却防刷屏，只关注正前方区域，减少无关干扰

## 🛠 技术栈

- **语言**：Kotlin
- **相机**：Android CameraX
- **端侧推理**：TensorFlow Lite（EfficientDet-Lite0，320×320 输入，COCO 90 类）
- **语音**：讯飞离线语音识别（AIKit）、Android TextToSpeech
- **云端**：SiliconFlow OpenAI 兼容 API（Qwen/Qwen3-VL-8B-Instruct 多模态大模型）
- **最低版本**：Android 7.0（Min SDK 24）

## 🚀 运行方式

### 1. 环境要求
- Android Studio Hedgehog 或更新
- JDK 17
- Android SDK 24+

### 2. 配置 API Key（重要）

本项目的 API Key **不写在源码里**，需要在 `local.properties`（位于项目根目录，已被 .gitignore 忽略）中配置：

```properties
# SiliconFlow 多模态大模型 API Key（用于联网识别，可选）
SILICONFLOW_API_KEY=sk-xxxxxxxx

# 讯飞离线语音识别凭据（可选，不配则语音控制不可用）
IFLYTEK_APP_ID=xxxx
IFLYTEK_API_KEY=xxxx
IFLYTEK_API_SECRET=xxxx
IFLYTEK_ABILITY_ID=xxxx
```

> 没有配置 key 也能编译运行，只是联网识别和语音控制功能不可用，离线检测功能正常。

### 3. 编译运行
```bash
./gradlew assembleDebug
```
APK 输出在 `app/build/outputs/apk/debug/app-debug.apk`，安装到 Android 7.0+ 真机即可。

## 🔄 开发过程与迭代记录

> 记录每一版解决什么问题、遇到什么瓶颈、如何改进。

### v1 — 离线检测版

- 实现 CameraX 取帧 + TFLite 推理 + TTS 播报的最小闭环
- **遇到的问题**：COCO 预训练模型不包含护栏、交通锥、电动滑板车、树干等类别 —— 这些恰恰是视障出行中最常见的障碍
- **瓶颈**：换模型需要重新训练与部署，端侧算力有限，模型体积也受限

### v2 — 联网增强版

- **解决方案**：接入 Qwen3-VL 多模态大模型，识别开放类别并生成自然语言描述
- **新问题**：完全依赖网络，电梯、地下通道、弱网场景下直接失效；且云端调用有延迟和费用
- **改进**：改为**双路径策略** —— 端侧结果置信度高时直接采用，置信度低或类别未覆盖时才请求云端；按网络状态自动切换，弱网下自动降级为纯离线

### v3 — 体验优化版

- **问题**：所有检测到的物体都播报，导致语音刷屏，视障用户来不及反应
- **改进**：
  - 按距离分级：0.5m 内紧急提示「小心」，2m 内提示绕行
  - 5 秒冷却机制，避免同一障碍物反复播报
  - 仅关注画面正前方区域，过滤两侧无关目标
- **补充**：加入讯飞离线语音识别，支持「找杯子」「停止识别」等语音指令，减少对触屏的依赖

### 已知不足与后续方向

| 不足 | 后续计划 |
|---|---|
| 单目测距为几何近似值，存在误差 | 引入双目/深度传感器或结合多帧校正 |
| 尚未进行真实视障用户测试 | 联系视障群体或志愿者进行可用性测试，收集反馈 |
| 缺少量化评测指标 | 建立准确率、误报率、端到端延迟的测试集 |
| 端侧类别覆盖有限 | 通过后处理规则或自训轻量模型补充 |
